<Section n="03" title="Guidelines">

<DoDont>
  <Do example={<SplitButton variant="primary" icon={ResolveIcon} onClick={() => {}} menuLabel="More ways to resolve" actions={[{ id: 'next-release', label: 'Resolve in the next release', onClick: () => {} }]}>Resolve</SplitButton>}>
    A default action with variations <em>of that action</em>.
  </Do>
  <Dont example={<SplitButton variant="primary" onClick={() => {}} menuLabel="More actions" actions={[{ id: 'delete', label: 'Delete project', onClick: () => {} }]}>Resolve</SplitButton>}>
    Unrelated actions behind the chevron. That is a menu.
  </Dont>
</DoDont>

<DoDont>
  <Do example={<Button variant="secondary" menu>Sort</Button>}>
    A plain menu button when there is no obvious default.
  </Do>
  <Dont example={<SplitButton variant="secondary" onClick={() => {}} menuLabel="Sort options" actions={[{ id: 'last-seen', label: 'By last seen', onClick: () => {} }]}>Sort</SplitButton>}>
    A split whose leading half nobody presses. Half the control is dead weight.
  </Dont>
</DoDont>

</Section>

<Section n="05" title="What it guarantees">

<Guarantees>
  <Guarantee story="TheHalvesAreIndependent">The two halves fire independently: the label runs the action, the chevron only opens the menu.</Guarantee>
  <Guarantee story="TheWholePillSinks">The whole pill sinks from either half, so the seam never opens.</Guarantee>
  <Guarantee>The halves take an inset focus ring, because the root clips: an outward ring on a child at the pill's edge would show on two sides only.</Guarantee>
</Guarantees>
