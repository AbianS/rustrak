<Section n="07" title="What it guarantees">

<Guarantees>
  <Guarantee story="Wired">Inside a <code>Field</code> it wires itself to the label and the error through Base UI; nothing has to be threaded by hand.</Guarantee>
  <Guarantee story="States">Read-only settles into the surface and keeps its text: what goes is the promise of a caret.</Guarantee>
  <Guarantee>The focus ring is on the box, not the control, so the whole field lights up as one thing.</Guarantee>
  <Guarantee><code>:read-only</code> is matched only on an <code>input</code> or <code>textarea</code> — in CSS it also matches a span or a button, which once painted every adorned field grey.</Guarantee>
</Guarantees>
