  <Guarantee story="SelectionIsNotOnlyColour">The selected tab gains weight as well as the rule, so somebody who cannot pick lime out still finds it.</Guarantee>
  <Guarantee>Base UI supplies <code>aria-selected</code>, <code>role="tabpanel"</code> and the roving focus; only the appearance lives here.</Guarantee>
