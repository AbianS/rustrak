## 4. Summary of everything that is not safe to build from

**Wrong, fix before implementation:**

1. **V6 — ky is 2.0.2, not 1.14.3.** The Stack table is a major version behind `packages/client`, which already uses ky-2-only APIs (`isHTTPError`, `error.data`, `prefix`). Anyone rewriting `utils/http.ts` from this table targets the wrong library.
2. **F6 — "re-exports are invalid" is not true.** The shipped TS plugin permits `export { x } from './y'` when `x` is async; only non-Promise-returning exports error. The rule is still worth having, but it must be *enforced* (an AD-9 check) rather than assumed from the compiler.
3. **C1 (59 → 57/54), C9 (26 → 28/31), C14 (10 → 9)** — three counting claims that do not reproduce.

**Confidently stated, not confirmable:**

4. **C19 — the 35/46 split and the "46 accidental endpoints".** The actual total is 85 exported actions; 35 + 46 = 81. This is AD-5's motivating fact and needs re-derivation.
5. **C20 — the seven-repo survey.** Load-bearing for two decisions, zero citations.
6. **F14 — `reset()` "cannot recover from Server Component errors".** The 16.2.10 docs support only the weaker "does not re-fetch". Softening the wording or testing the button would close this.

**Undisclosed risk:**

7. **V10 + V3 — ts-morph vs TypeScript 7.** ts-morph is healthy at 28.0.0 but breaks against TS 7 (legacy compiler API removed; stable replacement expected in TS 7.1, ~Oct 2026). The repo is on TS 6.0.3 so it works today, but TS 7.0.2 is already the registry `latest`, and AD-9 rule (2) — the spine's own "load-bearing rule" — is the thing that breaks on upgrade. Also, "latest stable at install" contradicts the spine's own exact-pinning convention.

**Everything else checked out.** All twelve remaining framework claims verify verbatim against the shipped Next.js 16.2.10 docs, the shipped compiler and TS-plugin source, the bundled React 19.2.7 flight serializer, or `@types/react`. The client, server-error, static-table, threshold-duplication, `useTransition`, `global-error`, Route-Handler, `components/ui`, Biome and `cookies()`-in-`createClient` claims all match the tree exactly — several of them to the line.
